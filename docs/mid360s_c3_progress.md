# MID360S C3 高频估计进度（2026-09-27）

## 已实现

- 独立 `kf_fast` 使用与激光滤波器相同的 `get_f/df_dx/df_dw` 模型、过程噪声、陀螺/加速度偏置、重力和 `G_m_s2/mean_acc.norm()` 原始加速度尺度。每条真实 IMU 驱动一次预测并更新完整状态与协方差，不再使用简化的位姿积分器。
- 保存最近 2 秒真实 IMU。每次有效激光校正将 `kf_fast` 恢复到扫描帧末的完整状态与 `P`，从该锚点重放缓存中时间较新的 IMU。跨帧末使用 C2 插值的 IMU 作为首个积分边界；时间不连续或缓存不足则停止高频发布。
- 两线程 executor 让 IMU 与匹配在不同回调组运行。扫描同步时短暂锁住传感器队列；匹配过程不持有队列锁。高频快照严格按源时间递增发布，pose/twist 协方差来自本次 `kf_fast`。
- TF 仍只有低频 `/Odometry` 的既有发布路径负责；高频路径没有发送同一边的第二份 TF。

## 离线回放

WSL ROS 2 Humble Release 构建通过。12.63 秒实测静态 bag 的一次回放产生 114 条低频、2244 条高频里程计。两路时间均严格递增，姿态/位置/速度有限，frame 一致，6 个 pose 协方差对角项均为正。启动和同步边界丢帧数随回放调度而变化，因此不以消息总数作为性能验收。
